## What This Is

`zzfisher` is an R package implementing Fisher's exact test for **r x 2 contingency tables** (arbitrary number of rows, two columns). It provides multiple algorithmic implementations across pure R, C, and C++ to explore performance characteristics of different pruning strategies.

All exported functions take a single integer matrix `dat` (r x 2) and return an `htest` S3 object (matching `stats::fisher.test()` output). The `tree_memo_profile` variant returns an `htest` with a `$profile` list of counters attached.

## Architecture: Two Algorithmic Families

### Tree-based (mode-centric traversal with pruning)

Traverses the space of possible tables starting from the mode (most probable table), expanding outward. Pruning strategies:

- **S1 (suffix-max bound):** If `prefix_prob * suffix_max <= p_obs`, no table in this subtree can exceed the observed probability. `tree_memo` uses the unconstrained product `prod(choose(r_i, floor(r_i/2)))`. `tree_dp` precomputes exact constrained max via `cmax[k][c1]`.
- **S2 (find_min bulk subtraction):** If the minimum-probability table exceeds `p_obs`, subtract prefix probability in bulk.
- **S3 (find_max exclusion):** If the maximum-probability table is below `p_obs`, skip the subtree.
- **S4 (mode-path dominance):** Only in `tree_memo_s4_c`. Cascade pruning when S3 fires on the mode path.

`find_max` and `find_min` results are memoized by `(k, c1)` key.

Current optimizations in tree_memo (R and C):

- dhyper recurrence in traverse (O(1) per sibling)
- Incremental log-probability in find_max
- S3-before-S2 pruning order
- Inlined penultimate handler for bottom two rows
- Dynamic hash capacity (power-of-two sizing based on state space)
- C implementations use `R_alloc` (interrupt-safe, no manual free)

| Function | Lang | Row order | Suffix-max | Notes |
|---|---|---|---|---|
| `tree_memo` | R | ascending | unconstrained | Reference; dhyper recurrence, penult inlining |
| `tree_memo_c` | C99 | ascending | unconstrained | Open-addressing hash, R_alloc, dynamic capacity |
| `tree_memo_s4_c` | C99 | ascending | unconstrained | Adds S4 mode-path dominance |
| `tree_memo_cpp` | C++ | ascending | unconstrained | `std::unordered_map`; has `PROFILE_V4` instrumentation |
| `tree_dp` | R | descending | constrained DP | Precomputes `cmax_mat` |
| `tree_dp_cpp` | C++ | descending | constrained DP | Best tree variant |

### Network-based (state-space enumeration)

Enumerates all feasible tables by recursing over rows, accumulating `prod(choose(r_i, y_i))` as a "factor." Works in factor space where `P(table) = D * factor` and `D = c1! * c2! / n!`.

- **Vandermonde bulk-sum:** When `prefix * suffix_max <= threshold`, the subtree factor sum equals `choose(suffix_r, c1)`.
- **All-above pruning:** When `prefix > threshold`, no completion qualifies.

| Function | Lang | Suffix-max | Notes |
|---|---|---|---|
| `net_vander_cpp` | C++ | unconstrained | Uses `R::choose` in hot path |
| `net_dp_cpp` | C++ | constrained DP | Pure C++ math (`std::lgamma`), no R API in hot path |

## Source Code Layout

- `R/htest_wrap.R` -- `make_htest()` wraps p-values in htest S3 objects
- `R/wrappers.R` -- Public wrappers calling internal `.func()` and wrapping in htest
- `R/tree_memo.R` -- Pure R tree traversal (ascending, unconstrained suffix-max)
- `R/tree_dp.R` -- Pure R tree traversal (descending, constrained suffix-max DP)
- `R/RcppExports.R` -- Auto-generated by `Rcpp::compileAttributes()`
- `src/tree_memo.c` -- C99 port with open-addressing hash, R_alloc, dynamic capacity
- `src/tree_memo_s4.c` -- C99 with S4 mode-path dominance
- `src/tree_memo_cpp.cpp` -- C++ port with `PROFILE_V4` optional instrumentation
- `src/tree_dp.cpp` -- C++ tree with constrained suffix-max DP
- `src/net_vander.cpp` -- Network with Vandermonde bulk-sum
- `src/net_dp.cpp` -- Network with constrained suffix-max DP
- `src/*_wrapper.cpp` -- Thin Rcpp wrappers for C functions

## Key Invariants

- All implementations use tolerance `tol = 3.45254e-7`.
- Column flipping: when `c[0] > c[1]`, columns are swapped so traversal works on the smaller column total.
- `MAX_ROWS = 20` and `MAX_N = 10000`/`10001` are hard limits in C/C++ code.
- C implementations use `R_alloc` (not `calloc`/`free`).
- The p-value is computed as `1 - sum(prob for tables more extreme than observed)`, initialized to 1.0 and decremented.
- `tree_memo.R` mirrors `tree_memo.c` 1:1 in algorithm structure.
